THE PROBLEM

Simple rules.
Interesting search.

The 8-Puzzle is a sliding-tile problem played on a 3 × 3 grid. It contains eight numbered tiles and one empty space. The objective is to move the tiles until they match a specified goal arrangement.

Each move slides a tile next to the empty space into that space. An AI search algorithm explores possible arrangements to find a path from the initial state to the goal state.

YOUR ASSIGNED ALGORITHM

Depth-First Search (DFS)

DFS explores one path deeply before backtracking to investigate other possibilities.
