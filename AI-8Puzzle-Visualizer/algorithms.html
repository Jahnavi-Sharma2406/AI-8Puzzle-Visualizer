Search Algorithms

Six approaches to finding a path from the initial state to the goal state.

Uninformed Search

Breadth-First Search (BFS)

Explores all states at one depth before moving to the next depth.

Principle: Uses a FIFO queue.

Advantages: Complete and finds a shortest path when all moves have equal cost.

Limitations: Requires large amounts of memory.

Completeness: Yes.

Optimality: Yes, for equal step costs.

Complexity: Time and space O(bd).

Uninformed Search

Depth-First Search (DFS)

Follows one branch as deeply as possible before backtracking.

Principle: Uses a LIFO stack.

Advantages: Often uses less memory than BFS.

Limitations: May explore a long path and does not guarantee the shortest solution.

Completeness: Yes in a finite graph with visited-state checking.

Optimality: No.

Complexity: O(bm) time; O(bm) space for a tree-search implementation. Graph-search space can be larger.

Uninformed Search

Depth-Limited Search (DLS)

Performs DFS but stops exploring when a specified depth limit is reached.

Principle: DFS with a maximum depth.

Advantages: Prevents endless exploration down deep branches.

Limitations: May miss a solution beyond the limit.

Completeness: Only if the goal is within the limit.

Optimality: No.

Complexity: O(bl) time and O(bl) space.

Uninformed Search

Iterative Deepening DFS (IDDFS)

Repeatedly runs depth-limited search, increasing the depth limit each time.

Principle: Combines repeated depth limits with DFS.

Advantages: Finds shallow solutions with relatively low memory use.

Limitations: Repeats work at earlier depths.

Completeness: Yes for finite branching.

Optimality: Yes, for equal step costs.

Complexity: O(bd) time and O(bd) space.

Informed Search

Greedy Best-First Search (GBFS)

Expands the state that appears closest to the goal according to a heuristic.

Principle: Prioritizes h(n), the estimated distance to the goal.

Advantages: Can reach a promising state quickly.

Limitations: Can be misled by the heuristic and does not guarantee the shortest path.

Completeness: With graph-search duplicate checking in a finite state space, yes.

Optimality: No.

Complexity: Worst-case exponential time and space.

Informed Search

A* Search

Chooses states using both the cost so far and the estimated remaining cost.

Principle: f(n) = g(n) + h(n).

Advantages: Finds optimal solutions with an admissible heuristic and appropriate graph-search handling.

Limitations: Can consume substantial memory.

Completeness: Yes under standard finite-branching, positive-cost conditions.

Optimality: Yes with an admissible heuristic for tree search, or suitable consistency/reopening rules for graph search.

Complexity: Worst-case exponential time and space.

Understanding the notation

b: Branching factor, or average number of successors per state.

d: Depth of the shallowest goal.

m: Maximum search depth.

l: Depth limit used by DLS.

g(n): Cost from the initial state to the current state.

h(n): Estimated cost from the current state to the goal.

f(n): Estimated total solution cost in A*, calculated as g(n) + h(n).
